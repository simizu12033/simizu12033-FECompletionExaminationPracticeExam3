FE模試③｜基本情報技術者 科目A

使い方
1. ZIPをすべて展開します。
2. index.htmlをブラウザで開きます。インストール不要です。
3. 60問に回答して採点します。各問の「解説表示」で解説と図解を確認できます。
4. 不正解の問題は再回答・再採点できます。初回レポートは維持されます。
5. 重要用語カードは118枚。自己評価の記録も保存されます。

学習記録はブラウザ内に保存されます。端末間では同期しません。
ファイルを移動した場合やブラウザのデータを削除した場合、保存を引き継げないことがあります。
安定した運用には、このフォルダ全体を静的Webサーバに配置してください。
画面下部の「出典の分析」に全60問の照合結果と参照URLを掲載しています。
解説・図解・正答は提供PDFの問題に合わせて作成しています。
UI参照：https://simizu12033.github.io/FECompletionExamination20240128/

GitHubへアップロードする場合、このフォルダ内の全ファイルとassetsフォルダを、同じ階層関係で配置してください。ZIP自体をアップロードするのではなく、展開した中身をアップロードします。
